# スクワット連打。 — 試作 v1 / 描画 v3

ビルド不要。`index.html` をブラウザで開くだけで遊べる30秒ゲームです。HTML・CSS・JavaScript・新規SVG・WebAudioを1ファイルに収録し、外部フォント・画像・CDN・通信を使いません。

## 開き方

リポジトリをダウンロードして `index.html` を開きます。スマホでは静的ホスティング、またはPCで `python3 -m http.server 8000` を実行して同じネットワークからアクセスできます。iPhone Safariの縦画面を想定しています。

## 遊び方

開始前に20〜300kgを5kg刻みで選択。3・2・1の後、30秒間プレイします。重量はプレイ中固定です。

- 足首・膝・股関節をまんべんなく押すと、しゃがむ→立つで1レップ。深さは最も遅い関節で決まります。
- 関節カウント差3〜5で警告、6で転倒。各関節のカウントは先行しても止まりません。
- 背中・体幹は時間で減少。ボタンで+18、どちらか0でフォーム崩壊。転倒・崩壊は1.5秒入力不能、進行中レップを破棄し両姿勢を60に戻します。時計と獲得済みレップは維持します。
- 推奨重量を超えると必要入力・フォーム減衰・震えが増加。「重い」は2打、「危険」は3打で関節カウント1。潰れゲージ100で即終了します。
- 危険時の深さ30%未満は、増加4/秒と回復5/秒を同時適用（差引1/秒回復）。操作不能中も潰れゲージと時計は進みます。
- A/S/D＝足首/膝/股関節、J/K＝背中/体幹。キー長押しの自動連打は無効。右上で消音できます。

終了時に3部位のXPを加算。失敗した未完了レップは加算せず、完了レップはすべて「フォーム崩壊しなかったレップ」として扱います（崩壊時点で未完了レップが破棄されるため）。満タン時のフォームタップはXPに入りません。自己ベストは1レップ以上成功した最大重量です。

## 調整・保存

`index.html` のJavaScript冒頭 `CONFIG` に時間・重量・必要回数・偏り・姿勢減衰・過負荷・潰れ・XP・推奨重量・音量を集約しています。数値変更後は再読み込みしてください。

localStorageキーは `yakkuru-squat-v1`。形式は `{ "xp": [下半身XP, 背中XP, 体幹XP], "best": 最大成功重量, "total": 累計レップ }`。Lvは1+floor(XP/100)、推奨重量は部位Lvから計算して5kg単位で切り捨てます。推奨値自体は300kgで制限せず、選べる重量のみ20〜300kgです。タイトル下の確認付きリセットで消去できます。保存不可時は画面に通知し、一時記録で続行します。file:// の保存範囲はブラウザに依存するため、継続利用は同じURLで開いてください。

## 描画 v3

文章仕様をもとに新規SVGで描いた、橙色＋クリーム色・丸い体・短い手足・巻き尾・半目の犬です。顔は左、尾は右の横向き。奥側の脚を暗くし、足首→膝→骨盤→曲線の背骨→頭を連動させます。

背中低下はC字、体幹低下は反り、両方低下はS字＋震え。先行関節ごとに、かかと浮き／膝の前滑り／骨盤の後退と前倒れを描き分けます。

失敗アニメーションは、股関節＝板倒れ＋外れたプレートの周回、膝＝腹滑り、足首＝後ろ倒れ、背中＝ボール1回転、体幹＝ブリッジ崩落とバウンド、潰れ＝紙のような扁平と横滑り＋バーベル2回バウンド。脱力顔は共通です。復帰時は倒れたまま開始位置へ滑り戻り、小さく起き上がります。

ゲームの `CONFIG`、1.5秒ロック、判定・XP・保存形式は変更していません。失敗直前の姿勢は保存対象外の描画用オブジェクトに保持し、ロック残り時間からアニメーションを進めます。両姿勢が同時に0になった場合は背中のボール演出を優先します。`VISUAL` は描画専用の定数です。

[状態別スクリーンショットと検証記録](TESTING.md#描画-v3-確認記録) を参照してください。画像は確認用であり、ゲーム本体からは読み込みません。
