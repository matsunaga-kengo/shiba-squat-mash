# 今日は下半身DAY — 試作 v1 / 描画 v10

ビルド不要。`index.html` をブラウザで開くだけで遊べる30秒ゲームです。HTML・CSS・JavaScript・新規SVG・WebAudioを1ファイルに収録し、外部フォント・画像・CDN・通信を使いません。

## 開き方

リポジトリをダウンロードして `index.html` を開きます。スマホでは静的ホスティング、またはPCで `python3 -m http.server 8000` を実行して同じネットワークからアクセスできます。iPhone Safariの縦画面を想定しています。

## 遊び方

開始前に20〜300kgを5kg刻みで選択。3・2・1の後、30秒間プレイします。重量はプレイ中固定です。

- 足首・膝・股関節をまんべんなく押すと、しゃがむ→立つで1レップ。深さは最も遅い関節で決まります。
- 関節カウント差3〜5で警告、6で転倒。各関節のカウントは先行しても止まりません。
- 背中・体幹は時間で減少。ボタンで+18、どちらか0でフォーム崩壊。転倒・崩壊は1.5秒入力不能、進行中レップを破棄し両姿勢を60に戻します。時計と獲得済みレップは維持します。
- 推奨重量を超えると必要入力・フォーム減衰・震えが増加。「重い」は2打、「危険」は3打で関節カウント1。潰れゲージ100で即終了します。
- 危険時の深さ30%未満は、増加4/秒と回復5/秒を同時適用（差引1/秒回復）。操作不能中も潰れゲージと時計は進みます。
- A/S/D＝足首/膝/股関節、J/K＝背中/体幹。キー長押しの自動連打は無効。右上で消音できます。

終了時に3部位のXPを加算。失敗した未完了レップは加算せず、完了レップはすべて「フォーム崩壊しなかったレップ」として扱います（崩壊時点で未完了レップが破棄されるため）。満タン時のフォームタップはXPに入りません。自己ベストは1レップ以上成功した最大重量です。

## 調整・保存

`index.html` のJavaScript冒頭 `CONFIG` に時間・重量・必要回数・偏り・姿勢減衰・過負荷・潰れ・XP・推奨重量・音量を集約しています。数値変更後は再読み込みしてください。

localStorageキーは `yakkuru-squat-v1`。形式は `{ "xp": [下半身XP, 背中XP, 体幹XP], "best": 最大成功重量, "total": 累計レップ }`。Lvは1+floor(XP/100)、推奨重量は部位Lvから計算して5kg単位で切り捨てます。推奨値自体は300kgで制限せず、選べる重量のみ20〜300kgです。タイトル下の確認付きリセットで消去できます。保存不可時は画面に通知し、一時記録で続行します。file:// の保存範囲はブラウザに依存するため、継続利用は同じURLで開いてください。

## 描画 v3

文章仕様をもとに新規SVGで描いた、橙色＋クリーム色・丸い体・短い手足・巻き尾・半目の犬です。顔は左、尾は右の横向き。奥側の脚を暗くし、足首→膝→骨盤→曲線の背骨→頭を連動させます。

背中低下はC字、体幹低下は反り、両方低下はS字＋震え。先行関節ごとに、かかと浮き／膝の前滑り／骨盤の後退と前倒れを描き分けます。

失敗アニメーションは、股関節＝板倒れ＋外れたプレートの周回、膝＝腹滑り、足首＝後ろ倒れ、背中＝ボール1回転、体幹＝ブリッジ崩落とバウンド、潰れ＝紙のような扁平と横滑り＋バーベル2回バウンド。脱力顔は共通です。復帰時は倒れたまま開始位置へ滑り戻り、小さく起き上がります。

ゲームの `CONFIG`、1.5秒ロック、判定・XP・保存形式は変更していません。失敗直前の姿勢は保存対象外の描画用オブジェクトに保持し、ロック残り時間からアニメーションを進めます。両姿勢が同時に0になった場合は背中のボール演出を優先します。`VISUAL` は描画専用の定数です。

[状態別スクリーンショットと検証記録](TESTING.md#描画-v3-確認記録) を参照してください。画像は確認用であり、ゲーム本体からは読み込みません。


## 描画 v4・結果画面

描画専用のばね追従と骨盤→膝→上体の0/32/68msの位相差を追加。立ち上がりの予備沈み、レップ後の減衰反動、視線の補正、尾のカウンターバランス、足裏の荷重移動、呼吸・耳・尾の待機動作を描きます。過負荷の震えは全身に伝えます。先行・崩れ・滑り・バウンドの振幅を概ね1.4倍にし、6種の失敗の筋書きと1.5秒ロックは維持しています。

犬は全画面で拡大。通常時は足裏が安定するカメラを使い、失敗時は演出の範囲を含めて見切れを防ぎます。結果の2ボタンはレップ・重量サマリー直下の上部にまとめ、表示後800msは無効です。ガード中に始めたポインター操作も破棄します。確認ダイアログは追加していません。タイトルのスタート位置は維持しています。

`PRESENTATION` と `VISUAL` は描画・結果UI専用です。CONFIG、ゲーム状態、XP、保存キー・形式は変更していません。[描画v4の確認画像と回帰検証](TESTING.md#描画-v4-確認記録)を参照してください。


## v5：肩のバー・重量別N

バーの接点を背骨上端の肩へ固定し、シャフト・プレート・握る手を同じ肩座標系で傾けます。前傾・背中の丸まり・反り・深しゃがみでも接点を維持します。板倒れで外れるプレートの出発・帰着も新しいシャフト位置へ合わせました。失敗の筋書き、v4のモーション・カメラ・結果UIは維持しています。

必要回数のみ `N = 2 + floor((重量−20)/50) + 過負荷追加分` に変更。CONFIGの変更は `baseN: 5 → 2` と `nWeightDivisor: 100 → 50` だけです。重量の20kgオフセットは既存の `minWeight` を使用。過負荷なしでは20〜65kg=2、70〜115kg=3、120〜165kg=4、170〜215kg=5、220〜265kg=6、270〜300kg=7。過負荷追加Nとタップ倍率は従来どおりです。

20kgは各関節2回×3関節×2フェーズ=12回の動き入力で1レップ。背中・体幹の回復も必要です。確認内容は[TESTING.mdのv5記録](TESTING.md#v5-肩のバーとn調整)を参照してください。


## v6：真横の円盤と重量表現

手前側円盤の中心を肩接点へ置き、奥の円盤は数pxずれた縁だけを見せます。長いシャフトを表示せず、背中側へ短い端と握る手だけを出します。重量ごとの手前円盤は、20〜45kg＝半径14・1枚、50〜95kg＝17・1枚、100〜145kg＝20・2枚、150〜195kg＝23・2枚、200〜245kg＝25・3枚、250〜300kg＝28・3枚。重なりは中心を2px/1pxずつずらした形です。

タイトルは選択中の重量、プレイ・結果・失敗はその回の固定重量を描画に使用します。板倒れでは手前1枚が外れて周回し、潰れではその重量の円盤が2回バウンドします。描画専用の `plateStyle` のみで表現し、CONFIG・N式・ゲーム処理・保存・v4モーション・結果ガードは変更していません。

[比較画像・回帰確認](TESTING.md#v6-真横プレートと重量表現)を参照してください。


## v7：現実離れした大円盤

`plateStyle` の半径を14／18／24／30／37／45へ差し替えました。重量範囲・枚数はv6のままです。最大と最小の半径比は約3.21倍、面積比は約10.33倍。重なりの横オフセットは `2 + (半径−14)×0.08`、縦はその半分にし、大きい円盤の重なりを広げます。

真横表示・円盤中心＝肩接点は維持。通常姿勢は肩や体を変更せず床クリアランスを確認しています。外れて転がる円盤の床基準と、潰れでバウンドする円盤の静止高さだけを半径に応じて決め、床への埋まりを防ぎます。円盤の周回・2回バウンドの時間軸や振幅、他のモーション・カメラ・ゲーム処理は変えていません。

[比較画像と検証結果](TESTING.md#v7-巨大プレート)を参照してください。


## v8：フォームピンチの吹き出し

背中／体幹が35以下になったら頭の近くに白い吹き出しをポップイン。50以上へ回復するまで維持します。両方なら「ぜんぶピンチ！」、どちらか15以下なら赤いギザギザ＋小刻みな震えと汗のしずくを出します。頭上を優先し、短い画面では犬を指すしっぽ付きで右上へ配置します。失敗アニメーション中・結果・カウントダウンでは表示しません。

閾値と履歴は `FORM_CUE`／`formCueState` という表示専用の状態で扱い、game・CONFIG・メーター・XP・保存データには書き込みません。犬・カメラのSVGとは別の操作を遮らないHTML/SVGレイヤーです。[確認画像と回帰記録](TESTING.md#v8-フォームピンチの吹き出し)を参照してください。


## v9：比例して育つ1枚の円盤

`plateStyle` を `radius = Math.round(13 + (weight−20)×0.29), count = 1` に変更。20kg=13、50kg=22、100kg=36、150kg=51、200kg=65、250kg=80、300kg=94です。手前は常に1枚、奥側の数pxの縁は残します。直径の伸び幅は26→188（162）で、v8の28→90（62）の約2.61倍です。

肩中心・実寸を保ち、既存の動的カメラと床→犬→手前円盤の順序を使います。巨大円盤は床ラインの一部を手前で隠す描画になります。300kgでは腕の大部分も円盤に隠れ、後ろ縁の少し先に握りだけが見えます。外れる円盤の周回と、潰れのバウンドには既存の半径依存床基準をそのまま使用します。

CONFIG・N式・ゲーム処理・モーション・吹き出し・保存・結果ガードは変更していません。[比較画像と回帰記録](TESTING.md#v9-比例する1枚の巨大円盤)を参照してください。


## v10：今日は下半身DAY・後方へ広がる荷物

タイトル見出し・タブ題名・共通ヘッダーを「今日は下半身DAY」、サブを「自分の限界を超えろ！」へ変更。シャフトは描画せず、握りは肩から `min(半径+4, 40)` に制限します。

円盤の径はv9と同じまま、中心を肩から `(半径−13)×0.8` だけ尻尾側へずらします。少し下へ置き、下端が床を超える場合は円盤中心のみを上へ補正。肩は動かしません。円盤を犬より後ろに描き、顔・胸・腕を見せ、手は円盤表面へ重ねます。

肩・円盤中心・握りは `barMount` から導出。外れる円盤の離脱／帰着も実際のマウントと同じ回転・反動から求め、潰れも同じ配置へ追従します。CONFIG・N式・判定・育成・保存・モーション・吹き出し・結果ガードは変更していません。[画像と検証記録](TESTING.md#v10-今日は下半身dayと後方荷重)を参照してください。
